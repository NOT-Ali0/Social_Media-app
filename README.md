## Project Overview

This is a **Social Media Web Application UI** built with **Svelte (without SvelteKit)** and **pure CSS**.

The project focuses on the front-end structure and user interface, simulating a Facebook-like experience.

### Features
- User authentication UI (Login & Registration)
- Home feed with posts
- User profile page
- Create, Read, Update, and Delete (**CRUD**) operations for posts
- Edit and delete post options (three-dots menu)
- Modal windows for comments and post editing
- Event-based communication between components
- Responsive and clean modern design
